# Koro
[![CI](https://github.com/veternitzz/koro/actions/workflows/ci.yml/badge.svg)](https://github.com/veternitzz/koro/actions/workflows/ci.yml)

Koro is an experimental toolchain for the [Luau](https://luau.org/) programming language. Koro's goal is to consolidate key Luau tooling into one tool. We plan to feature a general-purpose runtime, package manager, linter, testing suite, bundler, and binary compiler.
